# Power BI Dashboard

Import `data/processed/telco_customer_churn_clean.csv`.

## Page 1 — Executive Overview
Cards:
- Customers
- Churned customers
- Churn rate
- Average monthly charges
- Average tenure

Charts:
- Churn by contract
- Churn by internet service
- Churn by tenure group

## Page 2 — Customer Profile
Slicers:
- Gender
- Senior citizen
- Partner
- Dependents
- Contract
- Internet service
- Payment method

## Page 3 — Retention Analysis
Show:
- Churn rate by contract
- Churn rate by tenure
- Churn rate by payment method
- Churn rate by service

## Page 4 — Model Results
Show model comparison:
- Accuracy
- Precision
- Recall
- F1
- ROC-AUC

Do not present model output as a guaranteed prediction that a specific customer will churn.
